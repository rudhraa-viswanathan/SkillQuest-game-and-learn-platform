# SkillQuest – Game and Learn Platform

SkillQuest is a gamified learning platform where users learn skills through interactive activities and games.

## Project Structure

- SkillQuest Frontend – HTML, CSS and JavaScript frontend
- SkillQuest Backend – Spring Boot REST API backend

## Technologies

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- REST API
- Spring Security
- JWT
